\chapter{Representative Generated Output}
\label{app:generated}

This appendix includes selected generated output used to inspect the compiler
pipeline. The output is shortened where necessary for readability.

\section{IR\_TREE for Hello World}

    BLOCK TYPE=i32
    |   FUNCTION_CALL("printf") TYPE=unit
    |   |   CONST_STRING("hello world\n") TYPE=*i8
    |   CONST 0 TYPE=i32

fn printf(fmt: *i8, ...) -> unit
\end{lstlisting}

\section{Diagnostic Form}

The diagnostic printer reports an error message, file and line, the relevant
source line, and a caret underline. A representative diagnostic has this shape:

\begin{lstlisting}[caption={Representative diagnostic shape}]
error: expected expr of type i32, found bool
at example.epl:3
    let x: i32 = true;
                 ^^^^
\end{lstlisting}

\section{Useful Inspection Commands}

\begin{lstlisting}[caption={Compiler inspection commands}]
target/debug/epl ast examples/hello_world.epl
target/debug/epl ir_tree examples/comptime_primes.epl
target/debug/epl ir examples/fibonacci.epl
target/debug/epl cfg examples/fibonacci.epl
target/debug/epl llvm-ir examples/hello_world.epl
target/debug/epl llvm-obj examples/hello_world.epl
\end{lstlisting}

The object-file command emits \texttt{a.out.o}. The executable can be produced
by linking that object with a system C compiler.
